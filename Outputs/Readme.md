# Phylogenetic Tree Interpretation


## Tree Structure & Clustering
- The tree is **rooted**, indicating a common ancestor for all sequences.
- Sequences that are **closer together** on the tree share a more recent common ancestor.
- **Clusters (clades)** represent groups of sequences that are more similar in genetic composition.
- **Branch lengths** reflect genetic distance, with longer branches indicating greater genetic divergence due to mutations.


## Evolutionary Distance
- Sequences with longer branches have undergone more mutations, suggesting higher genetic divergence.
